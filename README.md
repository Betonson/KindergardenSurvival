# KindergardenSurvival

«Сад № 0. Всё пошло по плану. Почти» — мобильная браузерная игра для сотрудников детских садов «Синергия». В прототипе доступны вход, регистрация и настройки. После входа открывается «Мой сад». В шапке также доступны «Приключения» и «Коллекция». «Аватар» находится в настройках после «Аккаунта» и заменяет отдельный экран «Мой герой».

## Локальный запуск

Требуются Node.js 22.13 или новее и npm. В папке проекта выполните

```sh
npm ci
npm run dev
```

Откройте [локальный сайт](http://127.0.0.1:3000). Если порт занят, Next.js укажет выбранный адрес в терминале. Остановить сервер можно сочетанием Ctrl+C.

## Аккаунты и настройки

Аккаунты, сессии и настройка выдачи прав хранятся на сервере в локальной PostgreSQL-совместимой базе PGlite. Каталог по умолчанию — `.data/postgres`. Для отдельного экземпляра приложения задайте `ACADEMY_DATA_DIR` с другим каталогом. Один каталог обслуживает один процесс приложения. Пароли хранятся в виде хешей scrypt с индивидуальной солью.

При регистрации пользователь выбирает «Методист» или «Сотрудник». Для сотрудника обязательна специализация — воспитатель, помощник, специалист или другой сотрудник. От неё будет зависеть доступность приключений и материалов.

В **Настройки → Администрирование** администратор может изменить флаг «Выдавать новым пользователям полные права». По умолчанию он включён и при регистрации заменяет выбранную роль на «Администратор». Выбранная сотрудником специализация сохраняется. При выключенном флаге сохраняется выбранная роль. Флаг действует только на новые аккаунты. При обновлении прежние педагоги становятся сотрудниками, ранее неизвестная специализация остаётся пустой.

## Согласованные правила развития

В «Коллекции» методист и администратор видят весь каталог. Сотруднику сервер отдаёт материалы за завершённые приключения и вложенные в них предметы. В [каталоге коллекции](content/collection/catalog.json) материалы сгруппированы по темам. У каждого материала указан идентификатор приключения и перечислены его предметы. Сервер хранит одно прохождение на пару «аккаунт, приключение». Чтение карточки не влияет на доступ к награде.

Отложенные задачи и их приоритеты записаны в [TODO.md](TODO.md).

Когда появятся приключения, их прохождение будет сохраняться на сервере с привязкой к аккаунту и синхронизироваться между устройствами. Доступ к индивидуальным данным других сотрудников предусмотрен только для администратора. Посещения разделов не считаются игровым прогрессом. Соревнования отложены.

Для графики используем переданные фирменные материалы «Синергии», персонажа-носорога и корпоративную палитру. Художественный ориентир — комикс «История про тыкву». На обложке входа использованы его оригинальные кадры, фирменный логотип и изображение носорога из «Драконьего заповедника».
